🚀 Built an AI Resume Matcher using Python & Streamlit!

I recently worked on a project that compares a candidate’s resume with a job description and generates a match score using NLP techniques.

💡 The goal was to simulate how modern recruitment systems (ATS) evaluate resumes and identify the best fit.

🔍 Key Features:
✔ Upload resume (PDF)
✔ Input job description
✔ AI-based similarity scoring
✔ Match level indicator (Strong / Moderate / Weak)
✔ Clean and modern UI with custom styling

🛠 Tech Stack:
Python | Streamlit | NLP | Scikit-learn

📊 Core Implementation:
Used TF-IDF Vectorization and Cosine Similarity from Scikit-learn to measure the semantic similarity between resume content and job description.

🚀 What I Learned:

Applying NLP in real-world use cases
Working with TF-IDF and similarity metrics
Handling unstructured data (PDF resumes)
Building end-to-end AI applications
